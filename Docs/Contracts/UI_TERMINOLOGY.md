# UI用語と記号

読む条件: ボタン名、説明、翻訳、アイコンを変更するとき。
正本範囲: ユーザー向けの日本語・英語・記号の対応。動作は各機能契約が所有する。
関連要件: R-007, R-008, R-009。

Design status: ready

## 対象を区別する

| 対象 | 日本語 | English | 意味 |
|---|---|---|---|
| 作品単位 | プロジェクト | Project | 曲・調整結果・素材をまとめる作業単位 |
| アルバム内の音声 | 曲 | Song | マスタリングする一曲 |
| 比較先 | A / B | A / B | 比較する音を割り当てる比較枠。比較する音の名前ではない |
| 音声処理の保存状態 | 比較する音 | Comparison Audio | 原音、または調整を加えた音。内部データではVersionとして保持 |
| 未処理音声 | 原音 | Original | FXを適用していない音声。音量合わせ版とは区別 |
| プロジェクトの履歴番号 | 保存履歴 | Revision history | Versionとは別。通常のパッドにrevisionを露出させない |

「世代」「リビジョン」「パッチ」「テイク」を比較する音の同義語として混用しない。ユーザーの曲名・調整結果の名前は翻訳せず、そのまま表示する。

## 操作ラベル

| 操作 | 日本語表示 | English | 補足・記号 |
|---|---|---|---|
| A/Bで試聴 | A / B | A / B | 大きな文字だけ。選択枠で現在位置を示す |
| 非選択枠の版を送る | 音を切替 | Next Comparison Audio | 非選択側のA/Bを次の版へ循環。記号は変更対象、再生側は維持 |
| 再生・再開 | 再生 | Play | 三角 |
| 一時停止 | 一時停止 | Pause | 二本線。押すと位置を保持して停止 |
| 再生セッション終了 | 停止 | Stop | 四角。位置保持 |
| 先頭へ移動 | 先頭へ | Go to Start | 先頭線＋左三角 |
| 選択版を保存 | 書き出し | Export Audio | 箱へ入る下矢印。形式・保存先dialogを開く |
| 形式を指定した音声生成 | 書き出し | Export Audio | 曲制作・アルバム詳細操作で使用 |
| 作業単位の持ち出し | プロジェクトをエクスポート | Export Project | .aidaw.zip |
| 個人・機器の設定 | 設定 | Settings | 歯車 |
| 再生位置 | 再生位置 | Playback Position | 時刻または全曲波形 |
| モニター音量 | 再生音量 | Playback Volume | 書き出し音量は変えない |

カードのキー中央にA/B、下に「音を切替」。狭いキーに「Aの音を切替」を重複描画しない。版名・補足を小さな字で詰めず、strip/tooltipへ置く。旧循環操作は追加割当に残す。円形矢印はUndo/Redoと混同するため使わない。動作IDと保存済み配置IDは変更しない。

英語は翻訳の正本で、英語UIは未実装。意味を保ち144px画像/72pxキーで確認する。

配色はcomparison-palette.mjsを正本とし、A=青 #559CFF、B=アンバー #FFB638。非選択面はA=#1C293A、B=#30291F、文字と記号は対象のアクセント色。音を切替も対象側の非選択色を使う。選択時はアクセント色の面・暗い文字 #11161C・内枠・左上の点で区別する。再生の緑・停止の赤と分離する。暗い経過色はA=#173A66、B=#60401B。キー/波形/名前に共通使用し、A/B文字・位置・選択枠でも識別する。

アルバムの曲移動は「前の曲 / Previous Song」「次の曲 / Next Song」。基本4列目の上下へ↑/↓で縦に配置する。

マスタリングの機能・配置を固定し、色だけで判別させない。キー面は単色、光沢・虹色・斜線を除く。通常面は #20262E、文字 #E6EAF0。再生は暗緑面 #1C2E28 とミント記号 #65DDB0、停止は暗赤面 #322329 とコーラル記号 #F28B98。先頭・曲移動・書き出しは中立色。補助操作も中立色を基本とし、mute/cancelは赤、solo/採用は緑を記号へ使う。A/B以外へ青・アンバーの意味を広げない。有効キーの文字は背景と4.5:1以上（[WCAG](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)）、記号は3:1以上、無効は灰色＋入力拒否。主要アイコンは24px程度、SVGの線幅2px・丸い端で統一し、再生/停止とA/Bは面記号とする。曲送りは上下矢印、比較音送りはカード＋対象A/B＋右矢印、保存は下矢印＋受け皿。ラベルは9.5px・600、A/Bは30px・650。72pxで表示を確認する。
