# 再生と書き出し

起動は `npm --prefix Core run player`。編集はAI、再生・試聴はGUIで操作します。

ファイルメニューからProjects内の作品を開くか、`.aidaw.zip` をインポートします。選択はCodex／Claude Codeと共有されます。メイン画面にプロジェクト一覧を常時表示して自動ロードする方式ではありません。

既定のdeckは15キー・波形strip・4ノブを表示し、基本操作は左上4×2の8キーに収めます。キーは72pxの1×表示です。配置、skin、音声出力、機器、MIDI Learnは設定画面で選びます。

曲制作では再生・停止・頭出し・シークを中心に使い、ミキサーモードでトラックのmute/solo、試聴gain/panを操作します。試聴設定は保存済み作品を自動更新しません。作品へ残す操作は明示的に保存します。

マスタリングでは曲を選び、A/Bへ任意の保持版を割り当てて比較します。編集基点・採用版・比較先は別です。A/B切替は位置を引き継ぎますが、プラグイン再初期化による待ち時間があり、無音間隔ゼロではありません。

stripは曲全体の実測波形と再生位置を表示し、タップ・ドラッグで移動できます。音声未生成時に架空波形は表示しません。ノブの設定値は操作時に一時表示します。通常再生は位置とモニター音量、ミキサーではトラック選択・gain・panを操作します。

作品を持ち出すにはファイルメニューで `.aidaw.zip` をエクスポートします。音声書き出しは対象と形式を選びます。曲制作全体、マスタリングの選択曲／アルバムに対応し、WAV24・MP3・FLACを選べます。書き出し中の版は固定され、完了状態から成果物を取得します。

再生・試奏・書き出しは同じ音声処理枠で順番に実行します。再生中の書き出しが待機している場合は再生を停止すると進みます。完成済みファイルの取得と状態確認は並行できます。

MIDI Learnとメーカー専用bridgeの対応範囲は別です。設定画面に機種名があることだけで専用機能の実装・実機検証済みとは限りません。

UIを開発する場合だけ [操作面設計](../Architecture/CONTROLS.md)、機器を拡張する場合だけ [EXTENSIONS](../Contracts/EXTENSIONS.md) を参照してください。
