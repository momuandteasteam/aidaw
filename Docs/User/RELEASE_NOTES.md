# リリースノート

## 0.0.1 — AIDAW、新しいスタート

曲制作・マスタリング・ステム分離をまとめた初期開発版です。

これまでのリリースにひと区切りをつけ、**新しく0.0.1から仕切り直してスタートします。** 設計と開発の土台を整理し、曲制作・マスタリング・ステム分離を一つの環境で扱えるAIDAWとして再出発します。

### 設計・ディレクトリ構成・規約・開発方針を整理

本体の `Core`、作品の `Projects`、拡張の `Plugins`、素材・カタログの `Libraries`、作業手順の `Workflows`、設計・規約の `Docs` に責務を整理しました。ディレクトリ分け、各層の依存関係、文書の役割、作業ごとの読み取り経路をまとめ、開発の共通基盤を整備しています。

機能追加・バグ修正は設計文書を先に確定し、実装と検証の根拠を記録する方針を明文化しました。構成の詳細は [ディレクトリ構成](../Architecture/DIRECTORIES.md)、文書と開発方針は [文書規約](../Development/DOCUMENTATION.md) を参照してください。

### 目的に合わせた3タイプのプロジェクト

- **曲制作：** MIDI・オーディオのトラックを組み合わせ、音源・エフェクト・ミキサーで作曲からミックスまで進められます。
- **マスタリング：** 単曲・複数曲を管理し、曲ごとの処理や編集版を保存。A/B比較で仕上がりを聴き比べられます。
- **ステム分離：** 完成済み音声をボーカル・ドラム・ベース・その他の4パートに分離。各パートの試聴、全ステムZIPの保存、ミュート・ソロを反映した音声の書き出しができます。

### AIDAW DECKを実装

再生・停止・シーク・試聴・ファイルの読み込み・書き出しを直接操作できる **AIDAW DECK** を用意しました。音楽の編集はAIへ依頼し、すぐに聴きたいときは手元で操作できます。専用コントローラーなしで利用できます。

標準セットアップで本体とDECKを導入します。macOSはアプリケーション、Windowsはスタートメニューから起動できます。パッドとノブの割り当てに対応し、ノブの回転と押し込みは独立して設定できます。

### 作曲も、マスタリングも、手軽なステム分離も標準環境で

標準音源 **AIDAW GM** と、Gain・8バンドEQ・Limiter・Reverb・Enhancer・Imager・BassMonoを用意しました。**MTSで採用していたGoldenTips相当のマスタリング**を標準環境で行えるよう、GoldenTips方式を基準にしたEnhancerとマスタリング手順を整備しています。同一処理・同一出力を保証する意味ではありません。方式の詳細は [標準エフェクトDSP](../Contracts/STANDARD_DSP.md) を参照してください。

標準のステム分離には **Spleeterの4ステムモデル**を採用しました。対応AIクライアントとAIDAWをセットアップすれば、別のDAW、有料音源・エフェクト、分離専用アプリやサービスを用意せず、作曲・マスタリング・基本的なステム分離を始められます。必要な標準音源・エフェクト・分離モデルなどはセットアップで導入します。

### 無料で使えるオープンソース

AIDAW本体はAGPL-3.0-onlyで公開し、無料で利用できます。通常の音楽制作と、商用ソフト・サービスへの組み込みを分けた [利用規約・ライセンス案内](TERMS.md) を整備しました。

### この版の確認範囲

macOSで標準VST3の保存・復元・レンダリング、macOS ARM64で実Spleeterによる4ステム生成を確認しています。Windows・Linuxの実機検証や音質の聴取評価は未実施です。ステム分離は推定処理であり、他パートの音が残る場合があります。セットアップではDemucs/HTDemucsも外部から取得します。公開重みには科学研究用途という作者の説明があるため、利用前に [モデルの利用条件](../Contracts/SEPARATION.md) を確認してください。機種専用コントローラー連携には未実装部分があります。詳細な根拠と残件は [要件と対応状況](../Development/VERIFICATION.md) を参照してください。
