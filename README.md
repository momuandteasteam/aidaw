# AIDAW

**言葉で音楽を作り、手元のボタンですぐ聴く。**

Codex・Claude Code・Antigravityへの自然な言葉の指示で、曲制作・ミックス・マスタリングを進める **Vibe Coding DAW** です。

> **AIエージェントへ：** セットアップ・制作・開発を実行する場合、この下の人向けガイドを通読せず、[AGENTS.md](AGENTS.md) で作業を選び、該当する手順だけを読んでください。README自体の編集や説明を依頼された場合は、対象箇所を読んでください。

**対応OS：Windows 11・macOS・Linux（未検証）**

## はじめ方：AIにこのまま依頼する

ローカルのファイル操作とコマンド実行ができる **Codex・Claude Code・Antigravityのいずれか** を用意し、次の文章を貼り付けてください。

```text
https://github.com/momuandteasteam/aidaw.git をクローンして、
AIDAWを使用できるようにセットアップしてください。
リポジトリのAGENTS.mdに従って、今使っているAIクライアントとの接続を確認し、
再生用のGUIも起動してください。
```

すでにクローン済みなら、そのフォルダをAIで開いて「このAIDAWをセットアップして、使えるようにしてください」で始められます。

AIが必要な依存関係の準備、本体のビルド、標準音源・エフェクトの導入、AIからAIDAWを操作する接続設定を進めます。OSの認証やクライアントの信頼確認など、本人の操作が必要になった場合は案内に従ってください。接続を有効にするため、Codex／Claude Code／Antigravityの再読み込みや再起動が必要な場合があります。

セットアップ後の依頼例：

```text
AIDAWへの接続と利用できる機能を確認してください。
曲制作プロジェクトを新しく作成して、GUIで開いてください。
```

AIDAWのセットアップ用に追加のAPIキーを用意する必要はありません。利用するAIクライアントのアカウント・利用環境は別途必要です。

## AIDAWでできること

音源を選ぶ、演奏を作る、エフェクトを調整するといった編集はAIに依頼します。再生・停止・シーク・試聴・ファイルの読み込みや書き出しは、コンパクトなGUIから直接操作できます。再生のたびにAIの応答を待つ必要はありません。

| やりたいこと | AIDAWの使い方 |
| --- | --- |
| 曲を作る | MIDIとオーディオの複数トラックを組み合わせ、音源・エフェクト・ミキサーで仕上げます。 |
| 音声を分離する | 完成済み音声を4パートに分け、全ステムZIPや選択したパートの音声を保存できます。 |
| ミックスする | トラックの音量・パン・ミュート・ソロ、センド／リターン、マスターの処理を扱えます。 |
| マスタリングする | 複数の曲を一つのプロジェクトにまとめ、曲ごとの処理を調整し、切り替えて試聴できます。 |
| 編集前と聴き比べる | 編集履歴を残し、以前の状態へ戻せます。マスタリングでは過去の版をA/Bに選んで比較できます。 |
| 音声を出力する | WAV・MP3・FLAC、曲制作プロジェクトのトラック別ステムを書き出せます。マスタリングでは曲単位・アルバム全体を選べます。 |
| 作品を持ち出す | 編集データと履歴を `.aidaw.zip` にまとめてエクスポートし、インポートできます。 |

現在は開発中です。機種専用のコントローラー連携など、まだ完成していない部分があります。詳しい範囲は [要件と対応状況](Docs/Development/VERIFICATION.md) で確認できます。

## こんなふうに話しかけて使います

以下はターミナルのコマンドではなく、**AIに送る依頼文**です。曲名、テンポ、ファイル名などを自分の希望に置き換えてください。音声を使う場合はファイルを添付するか、AIがアクセスできる保存先を伝えます。

### 曲を作る

```text
「夜の散歩」という曲制作プロジェクトを作成して。
90 BPMの落ち着いた曲にしたい。
ピアノ、ベース、ドラムで、まずは8小節作ってください。
標準音源のAIDAW GMを使ってください。
```

```text
今開いている曲のドラムを少し控えめにして、
ピアノにリバーブを足してください。
```

使いたい音源があれば、その名前も伝えられます。AIは利用できる音源や内部ライブラリを確認して制作を進めます。GUIで開いたプロジェクトはAIと共有され、編集手順では操作前に対象を確認します。

### マスタリングする

```text
マスタリングプロジェクト「ミニアルバム」を作成して、
添付した3曲を読み込んでください。
曲ごとの音量感や音色の違いを確認しながら整えたいです。
```

```text
2曲目の高域を少し穏やかにしてください。
変更前と変更後をA/Bで聴き比べられるようにしてください。
```

### 以前の状態に戻す

```text
今のプロジェクトの編集履歴を確認して、
直前の変更前の状態に戻してください。
```

以前の状態へ戻す操作も履歴に残ります。マスタリングの比較では、聴き比べる版を選ぶことと、その版を採用することを分けて扱えます。

### 書き出す・保存する

```text
この曲をWAVとMP3で書き出してください。
```

```text
曲制作プロジェクトのトラックを、それぞれステムとして書き出してください。
```

```text
マスタリングしたアルバム全体をWAVで書き出してください。
```

```text
編集を続けられるように、このプロジェクトを.aidaw.zipでエクスポートしてください。
```

音声の書き出しと、編集用プロジェクトのエクスポートは別の操作です。普段のプロジェクトはAIDAW直下の `Projects/` に保存されます。GUIのファイルメニューから作品を開いたり、プロジェクトをインポート／エクスポートしたりできます。

### 完成済み音声をステム分離する

```text
ステム分離プロジェクトを作成して、添付した音声を分離してください。
ボーカル・ドラム・ベース・その他のステムをZIPで保存したいです。
```

```text
ボーカルだけミュートして、伴奏をWAVで書き出してください。
```

GUIでは「新規プロジェクト → ステム分離」を選び、原音を読み込んで開始します。「ファイル → ステム分離・ダウンロード」から、全ステムのZIP保存や、ミュート・ソロを反映した音声の保存ができます。原音と編集履歴は保持します。

標準エンジンは **Spleeterの4ステムモデル** です。コード・学習済みモデルのMITライセンスを確認して採用しています。分離結果は推定のため、他のパートの音が残る場合があります。Demucs本体とHTDemucsモデルもセットアップ時に取得・導入します。リポジトリには同梱しません。Demucsの公開重みには科学研究用途という作者の説明があり、ダウンロード方式でも利用条件は変わりません。根拠と仕様は[ステム分離](Docs/Contracts/SEPARATION.md)へ。

## 使える音源・エフェクト・ファイル

### 手持ちの音源やエフェクトを名前で指定

**VST3（macOS・Windows 11・Linux［未検証］）とAudio Units／AU（macOS）** の音源・エフェクトを利用できます。「このインストルメントを使って」「このエフェクトをかけて」のように、製品名やプリセット名を伝えてください。

```text
手持ちのKontaktで使えるピアノのライブラリを調べて、
その中から柔らかい音を選んで制作してください。
```

```text
インストール済みのFabFilter Pro-Q 3を使って、
ベースの低域を整理してください。
```

上の製品名は指定方法の例です。手元にインストールされ、必要な認証が済んだ対応プラグインを使います。AIが検出・読み込みと利用できるライブラリを確認します。すべての製品・プリセット形式への対応を保証するものではありません。VST2は対応対象に含めていません。

手持ちの音源がなくても、セットアップに含まれる **AIDAW GM** と **EQ・Limiter・Reverb** を指定して始められます。

### 対応するファイル形式

| 用途 | 形式・条件 |
| --- | --- |
| 音声の読み込み | WAV・AIFF・FLAC・Ogg Vorbis。MP3などの追加形式はOS・デコーダーに依存します。 |
| 音声の書き出し | WAV（24 bit）・MP3（320 kbps）・FLAC。いずれも48 kHz・ステレオ。 |
| 演奏データ | MIDIの読み込み・書き出し。音声ではなく、音程や演奏タイミングのデータです。 |
| 編集用プロジェクト | `.aidaw.zip` のインポート・エクスポート。音源プラグイン自体のインストールは別途必要です。 |

現在の音声処理は **48 kHz** です。44.1 kHzなどの素材を使う場合は、AIに「原音を残して48 kHzへ変換してから読み込んで」と依頼してください。読み込めない形式も、まずWAVへの変換を依頼できます。

## 自分でコマンドを実行する場合

ターミナルで、保存したい場所に移動してから実行します。通常は上のAIへの依頼だけで進められます。

```sh
git clone https://github.com/momuandteasteam/aidaw.git
cd aidaw
```

**macOS：**

```sh
bash Core/Tools/setup.sh --client codex
```

**Windows 11（PowerShell）：**

```powershell
powershell -File Core/Tools/setup.ps1 --client codex
```

**Linux（未検証）：** [導入手順](Docs/User/QUICKSTART.md)を参照してください。

Claude Codeは `--client claude`、Antigravityは `--client antigravity`、三者まとめて設定する場合は `--client all` に変更します。`--client both` はCodexとClaude Codeの組み合わせです。セットアップ後、必要に応じてAIクライアントを再読み込みし、GUIを起動します。

```sh
npm --prefix Core run player
```

既存の設定や保存先を引き継ぐ場合は [クイックスタート](Docs/User/QUICKSTART.md)、別のPCを音声処理サーバーにする場合は [遠隔接続](Docs/User/REMOTE_SERVER.md) を参照してください。

## 自分で直した機能を作者へ届ける

使用中にAIと直した不具合や追加した機能は、AIDAWへ還元できます。Gitの操作が分からなくても、AIに次のように頼めます。

```text
この変更を作者に共有して、プルリクを作成してください。
```

AIが変更内容とテストを確認し、GitHubにレビュー用の提案を送る準備・操作を進めます。初回はGitHubへのログインが必要です。作品・音声・個人設定は共有対象に含めません。詳しくは[開発参加](Docs/Development/CONTRIBUTING.md)をご覧ください。
